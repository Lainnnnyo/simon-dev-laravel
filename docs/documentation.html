Project overview

Byte & Brew is a café-themed Laravel POS application for staff to manage products, customers and staff accounts, record a one-product sale, update inventory, and inspect sales history. It uses a relational database and Laravel's MVC structure.

Tools and technologies

Laravel 13, PHP, Composer, Breeze authentication, Eloquent, migrations/seeders, Blade, MySQL on Wasmer, SQLite for local testing, Intervention Image/GD, Laravel Storage, Git and GitHub. Browser assets use plain CSS and small JavaScript enhancements.

ARCHITECTURE / RELATIONSHIPS

Data and application structure

Each sale belongs to one product and one recording staff member; its customer is optional. Products may be archived. Customers and users use soft deletion, keeping their historical references valid. Sale name and price snapshots preserve what was recorded even after later edits.

Controllers accept and validate requests; Eloquent models define relationships; Blade views display forms and results. SaleService locks database rows inside a transaction, computes totals from the stored product price, deducts stock, and creates the sale. Any failure rolls back both changes. Integer-cent arithmetic avoids floating-point price calculations.

Authentication middleware requires login. Staff status is checked on management routes. Administrator authorization protects staff-account management. Public registration is disabled; the first administrator is provisioned privately using an Artisan command.
